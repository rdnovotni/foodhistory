# Phase 1 PostgreSQL migrations

Run the migration files in lexical order. The files implement the Phase 1A–1C backend profile from the database data dictionary.

Important implementation notes:

- UUIDv7 domain IDs are generated by the application/import layer. PostgreSQL does not need a UUIDv7 extension.
- Taxonomy terms are seeded after `0008_foreign_keys_constraints.sql` using `../seeds/seed_taxonomy.py`.
- `0009_indexes.sql` intentionally uses ordinary indexes for search/filter performance. Only current-holding and file-checksum rules are unique.
- Large binaries are stored in object storage; only metadata lives in PostgreSQL.
- Phase 2 tables from the larger schema are deliberately omitted from this migration set.
